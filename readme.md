## Week 5 — final prototype
The live page runs `docs/`: one linear sequence — **plant** (press and hold the soil) → **water** (drag the rusty bucket and pour) → **wake** (circle slowly around the bud).

**Tool panel:** press **P**, or open the live page with `?panel` at the end of the URL. It edits the palette and the behaviour of each step live; **Copy settings** copies the values plus an instruction to paste back into Claude Code, **Restore defaults** goes back to `docs/settings.js`. Set `window.PANEL_VISIBLE` in `docs/settings.js` to show or hide it by default.

Settings variations for the process document are in `process/`.
